Handover Checklist — Detailed

Before handover
- [ ] Confirm repository permissions for incoming maintainers
- [ ] Ensure secrets & service accounts are accessible via secrets manager
- [ ] Provide deployment credentials and pipeline access

Documentation
- [ ] TECHNICAL.md complete and reviewed
- [ ] RUNBOOK.md reviewed for operational steps
- [ ] ONBOARDING.md tested by a new joiner
- [ ] EXAMPLES.md includes end-to-end sample runs

Operational handover
- [ ] Demonstrate start/stop/restart procedures
- [ ] Perform a live smoke test and record results
- [ ] Validate monitoring dashboards and alert routing

Knowledge transfer
- [ ] Walkthrough architecture and component responsibilities
- [ ] Walkthrough common incidents and playbooks
- [ ] Provide list of open issues and planned work
