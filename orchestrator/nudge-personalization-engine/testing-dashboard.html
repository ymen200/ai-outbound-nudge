Message Generator (port 8000) ▼

.\venv\Scripts\activate.bat
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000

cd "sequence generator"
.\venv\Scripts\activate.bat

DEBUG_MODE Information

DEBUG_MODE=true (default for testing)

  • Every message generation starts from a clean slate
  • Test runs are deterministic and repeatable
  • do_not_contact lists are still enforced

DEBUG_MODE=false (production)

  • Full memory active - reads prospect history
  • Avoids repeating hooks/angles
  • Learning loop tracks quality scores over time
